# my-home-server-alicerce
Framework de infraestrutura e automação para servidores domésticos Linux. Conta com instalador modular, painel CLI interativo, rotinas de manutenção autônomas com autorreparo do APT, gestão de rede, Samba, UFW e salvaguardas inteligentes de tráfego para reboot seguro.


Instalação 

```bash
git clone https://github.com/GustavoGianeli/my-home-server-alicerce.git &&
cd my-home-server-alicerce &&
chmod +x install-home-server.sh &&
sudo ./install-home-server.sh
```
